# Biografije Poznatnih Ličnosti

TPTP | Završni projekat — Grupa 30

FET Tuzla | vanr.prof.dr. Samra Mujačić | 2025/2026

## O projektu
Ovaj projekat predstavlja modernu, responzivnu web lokaciju posvećenu biografijama i dostignućima istorijskih ličnosti iz oblasti nauke, umjetnosti, književnosti i vladavine. Stranica nudi čist i pregledan prikaz informacija kroz organizovane sekcije, tabelarni prikaz podataka, galeriju i interaktivnu mapu. Korisnicima je omogućeno dinamičko filtriranje biografija po kategorijama u realnom vremenu, kao i ručno prebacivanje na tamni mod rada.

## Tehnologije
- **HTML5** (Semantički tagovi, struktura formi, mapiranje slika i iframe integracija)
- **CSS3** (CSS Grid raspored, Flexbox pozicioniranje, medijski upiti i CSS varijable, bez eksternih frameworka)
- **JavaScript** (Vanilla JS, DOM manipulacija, event listeneri, bez vanjskih biblioteka)
